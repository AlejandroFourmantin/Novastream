# 🎬 Nova Stream

¡Bienvenidos al repositorio de **Nova Stream**! 🚀
Esta es una plataforma de streaming 100% digital, diseñada para ofrecer la mejor experiencia de entretenimiento en películas y series, con una interfaz moderna y cinematográfica.

## 📌 Características del Proyecto

* **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio.
* **Interfaz de Usuario (UI):** Estilo oscuro (Dark Mode) inmersivo, ideal para plataformas de entretenimiento.
* **Páginas Incluidas:**
  * Inicio (Catálogo y presentación)
  * Sobre Nosotros
  * Planes y Suscripción
  * Iniciar Sesión / Registro
  * Página de Error 404 personalizada ("Señal Perdida")

## 🛠️ Tecnologías Utilizadas

Para el desarrollo de este proyecto se utilizaron las siguientes tecnologías:

* **HTML5:** Estructura semántica del sitio.
* **CSS:** Estilos personalizados y variables de color.
* **Bootstrap 5:** Framework para el sistema de grillas (grid), utilidades de espaciado y componentes responsive.
* **Bootstrap Icons:** Iconografía de la plataforma.

## 🎨 Paleta de Colores Principal

* **Cian Nova:** `#1DA1F2` (Color de acento y botones)
* **Fondo Oscuro:** `#1C202B` y `#212529`
* **Textos:** Blancos y grises semitransparentes (`text-white-50`)
